## 📌 Overview

This repository satisfies the requirements for **BCSE0593: Data Science and Visualization Lab - Experiment 01**. The primary goal of this experiment is to establish an end-to-end data acquisition, profiling, and version-controlled workflow using industry-standard tools[cite: 1].

### Key Objectives
* **Platform Configuration**: Register and configure professional developer accounts on Kaggle and GitHub[cite: 1].
* **Data Ingestion**: Search, filter, and extract open-source datasets from Kaggle[cite: 1].
* **Exploratory Data Analysis (EDA)**: Programmatically inspect data structures, verify null counts, and generate descriptive statistics using Pandas.
* **Version Control & Documentation**: Initialize a public Git repository, write technical documentation, and record version histories[cite: 1].
